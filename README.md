# Панелька Ночь

Маленькая хэллоуинская игра в духе Zelda GBC / Oracle of Ages. Жулебино, 31 октября.
Ваня в костюме привидения находит дедов кассетник: сторона A — обычная Москва, сторона B — Москва Духов.

Один файл: открой `index.html` в браузере. Работает на компьютере и телефоне.

## Управление

| | Клавиатура | Геймпад |
|---|---|---|
| Ходить | Стрелки / WASD | Крестовина / стик |
| Действие, удар | Z / Пробел | A |
| Перевернуть кассету | X / Shift | B |
| Фонарь | C | X / Y |
| Старт, пропустить | Enter | Start |

На телефоне — экранные кнопки.

## Боссы

1. Баба Зина — Кузьминский лес
2. Панелька — подъезд у МФЦ
3. Тыква — тёмная поляна в Кузьминках

## Чит

Во время игры набери `1907` — откроется меню выбора уровня.

В ролях: Виталёс, Андрей, Павлик, Рамиль, Ярик, Антон и баба Зина.
